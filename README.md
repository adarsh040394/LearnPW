# Learning Playwright Batch

This repository contains code and examples for learning Playwright, an open-source automation framework for web testing and scraping.

## Project Structure

- `chapter_01_Basics/` - Basic concepts and setup
- `chapter_02_Java_concepts/` - JavaScript concepts relevant to Playwright
- `chapter_16_OOps/` - Object-oriented programming examples

## Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/adarsh040394/LearnPW.git
   cd LearnPW
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Running Tests

To run the Playwright tests:
```bash
npx playwright test
```

To run tests in headed mode (visible browser):
```bash
npx playwright test --headed
```
